## 2514
1. 注意边界：如果right=left+1，两张都不删所以贡献也是0.
```cpp
if (right <= left + 1) dp[left][right] = 0;
```
2. 思路关键：
- 对于区间[l,r]，设**最后删除**的是牌k，则最后一次贡献应当是a[l-1]*a[k]*a[r+1]
- 故不妨在原数组首尾补1，dp[l][r]定义为**l、r保留不删**的最大贡献值
- 则：$dp[l][r]=\max(dp[l][k]+a[l]a[k]a[r]+dp[k][r])$

### 边界处理
由于cnt遍历到-1时需要手动改0，为了避免复杂的边界处理，不妨**采用1-based方式**，并补上dp、cnt的初始条件

### 具体的代码与解释
#### 初始化
cnt应按1计，因为有**1种空串的方案**。从此后cnt的状态转移中可以更容易理解这一点。

```cpp
    dp[0][0] = 0;
    for (int i = 0; i < n; i++){
        cnt[i][0] = 1;
    }
    for (int i = 1; i < m; i++){
        cnt[0][i] = 1;
    }
```
#### **情况1:a[i]=b[j]**
1. 思路阐释
- 假设已经得到此时最优解长度dp[i][j].我们需要考虑达到这个长度的所有可能的方案。故分别考虑a[i]b[j]的选取
- 如果a[i]b[j]都不选用：但dp[i-1][j-1]严格小于dp[i][j]，所以不可能。
- 如果都选用：那么和dp[i-1][j-1]无异
- 如果一个用一个弃：那么该方案成立的充分必要条件是“一个用一个弃”对应的最优长度=当前最优长度。

2. 具体代码片段
```cpp
    for (int i = 1; i < n; i++){
        for (int j = 1; j < m; j++){
            if (a[i] == b[j]){
                dp[i][j] = dp[i - 1][j - 1] + 1;
                cnt[i][j] = cnt[i-1][j-1];
                if (dp[i][j] == dp[i-1][j]) cnt[i][j] = (cnt[i][j] + cnt[i-1][j])%MOD;
                if (dp[i][j] == dp[i][j-1]) cnt[i][j] = (cnt[i][j] + cnt[i][j-1])%MOD;
            }
            ...
        }
    }
```
3. 对应的例子（也是想法的来源）
考虑`AA`与`A`的匹配，如果只按cnt[i-1][j-1]计，显然偏少。

#### **情况2:a[i]!=b[j]**
1. 思路阐释
- 如果dp[i][j-1]和dp[i-1][j]的最优长度不同，那么是容易的
- 如果相同， 那么合法的方案数应当是
$$方案[i][j-1]\cup 方案[i-1][j]\\
= 方案[i][j-1]+ 方案[i-1][j]-方案[i][j-1]\cap方案[i-1][j]
$$
- 上述应当减去交集：这意味着a[i]、b[j]都不采用，而可以都不采用需要满足
$$
dp[i-1][j-1]=dp[i][j]
$$
- 需要注意上述交集的减去**有前置条件**
2. 具体代码片段
```cpp 
            else {
                dp[i][j] = max(dp[i][j - 1],dp[i-1][j]);
                if (dp[i][j-1] == dp[i-1][j]){
                    cnt[i][j] = 0;
                    if (dp[i-1][j-1] == dp[i][j]) cnt[i][j] = (cnt[i-1][j] + cnt[i][j-1] + MOD - cnt[i-1][j-1])%MOD;
                    else cnt[i][j] = (cnt[i-1][j] + cnt[i][j-1])%MOD;
                }
                else{
                    if (dp[i][j-1]>dp[i-1][j]) cnt[i][j] = cnt[i][j-1];
                    else cnt[i][j] = cnt[i-1][j];
                }
```
